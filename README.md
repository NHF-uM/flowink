# FlowInk 墨水屏使用说明书

## 基础操作流程
1. 按下**电源按键**，唤醒芯片
2. 短按**模式按键**，观察**模式指示灯**，选择需要的工作模式
3. 在选中的模式下，**长按模式按键**，进入对应模式运行
4. 屏幕完成图片刷新；刷新完成15秒后，设备自动进入休眠

> 提示：轮播模式会自动唤醒刷新图片；**每次设备唤醒，唤醒时间都会重新计时**

## 工作模式说明
### 模式一：轮播模式｜模式指示灯：快速闪烁
读取TF卡内配置文件，从配置指定的**起始文件路径**开始循环播放图片。
图片刷新完成后等待15秒自动休眠；到达设定**轮播间隔**，设备自动唤醒刷新下一张图片。

### 模式二：服务器模式｜模式指示灯：慢速闪烁
1. 手机/电脑连接设备WiFi热点：`FlowInk‑AP`，密码：`hhhhhhhh`
2. 打开浏览器，输入网页：`http://192.168.4.1/`
2. 根据网页提示，上传BMP或其他格式图片，屏幕完成刷新显示。

## 设备三种工作状态
### 唤醒状态
设备已唤醒，支持按键操作
- 短按**模式按键**：切换工作模式
- 双击**电源按键**：屏幕刷成全白，随后进入休眠

### 刷图（屏幕刷新）状态
**电源指示灯闪烁**
> ⚠️屏幕保护提示：请等待指示灯熄灭后，再进行其他按键操作，不要中途打断刷新。

### 休眠状态
设备休眠，所有按键无响应
- 单击**电源按键**即可唤醒芯片

## 按键功能
### 电源按键
- 休眠状态：单击唤醒芯片
- 唤醒状态：双击 → 屏幕刷白，进入休眠

### 模式按键
- 唤醒状态**短按**：切换工作模式，通过模式指示灯确认模式
- 选定模式后**长按**：启动进入该模式

## 指示灯对照表
| 指示灯     | 状态     | 说明                     |
| ---------- | -------- | ------------------------ |
| 电源指示灯 | 常亮     | 设备正常工作（唤醒状态） |
| 电源指示灯 | 熄灭     | 设备休眠                 |
| 电源指示灯 | 闪烁     | 正在刷新屏幕，请勿操作   |
| 模式指示灯 | 快速闪烁 | 轮播模式                 |
| 模式指示灯 | 慢闪烁   | 服务器模式               |

## BMP图片制作
Release 文件夹提供转换工具：`convert.exe`、`converterTo6color_all.cmd`

方式1【单张转换】：直接将图片拖拽到 `convert.exe`，自动生成适配图片
方式2【批量转换】：把待转换图片放到与`convert.exe`相同文件夹，双击运行 `converterTo6color_all.cmd` 批量转换

## ⚠️墨水屏寿命保护规范（请遵守）
1. 画面不要频繁刷新，两次刷新间隔建议至少3分钟
2. 同一画面请勿静止显示超过24小时；如需长时间放置设备，优先将屏幕刷成全白，防止残影损伤屏幕

## TF卡故障排查（轮播模式刷新内置图片）
按顺序逐项检查：
1. TF卡内没有有效的BMP图片文件
2. TF卡识别异常
   - TF卡松动：取出TF卡，用纸巾擦拭金属触点后重新插入
   - 文件系统损坏：电脑格式化TF卡为 **FAT32**

### TF卡使用注意事项
1. 文件名仅使用英文、数字，**禁止中文命名**，文件名长度不超过127个字符
2. 配置文件丢失/误修改，设备自动使用默认参数：
   - 轮播间隔：6小时
   - 关闭子文件夹循环轮播
   - 仅刷新TF卡读取到的第一张图片
3. Release文件夹内有标准配置文件，复制放置到TF卡**根目录**即可生效

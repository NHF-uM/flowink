当墨水屏刷新内置图片的时候，请逐项检查：

1. TF 卡内无有效 BMP 文件
2. TF 卡未装载，若已装载
	1. TF 卡是否松动，触点是否有污渍（用纸巾擦拭）
	2. TF 卡文件系统损坏，需要用电脑将其格式化为 FAT32 格式

TF 卡：
1. 文件名不要长于127个字母/数字，不要使用中文命名
2. 配置文件若丢失或意外修改，程序将按默认值执行：
    1. 轮播间隔为 6 小时
    2. 关闭子文件循环轮播
    3. 刷新 TF 卡读取到的第一张图片
3. Release 文件夹含有标准配置文件，放置到 TF 卡根目录即可

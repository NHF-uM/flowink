# FlowInk 墨水屏使用说明书

## 基础操作流程
1. 按下**电源按键**，唤醒芯片，等待**模式指示灯**快闪（硬件初始化成功，默认处于模式一）
2. 短按**模式按键**，观察**模式指示灯**，选择需要进入的工作模式
3. 在选中的模式下，长按**模式按键**，运行对应程序
4. 图片刷新，刷新完成后设备自动进入休眠

## 工作模式说明
### 模式一：轮播模式｜模式指示灯：快速闪烁
1. 读取TF卡内配置文件，从文件内指定的**起始文件路径**开始循环播放图片
2. 图片刷新完成后自动休眠
3. 到达设定**轮播间隔**时间后，设备自动唤醒并刷新TF卡下一张图片

> 提示：
> 1. TF卡读取出来的顺序一般会按照修改先后顺序（比如用电脑新放入一张图片，无论放在哪个文件夹，正常情况下都是最后一张被读出）
> 2. 每次设备被唤醒，唤醒等待时间都会重新计时

### 模式二：服务器模式｜模式指示灯：慢速闪烁
1. 手机/电脑连接WiFi热点。热点名称：`FlowInk‑AP`，密码：`hhhhhhhh`
2. 打开浏览器，进入网页：`http://192.168.4.1/`
3. 根据网页提示，完成裁剪和图像处理并上传图片，屏幕还自动刷新图片
4. 图片保留 24 小时，到达时间后进入轮播模式并刷图

## ⚠️墨水屏寿命保护规范
1. 画面不要频繁刷新，两次刷新间隔建议至少**3分钟**（可以唤醒设备，但是尽量控制“长按进入对应模式”的间隔时间）
2. 同一画面请勿静止显示超过24小时；如需长时间放置设备，优先将屏幕**刷成全白**，防止残影损伤屏幕
    1. 长期存放处理：长按**电源按键**刷白屏幕，等待**电源指示灯**熄灭后短按**电源按键**进入永久休眠

3. 不要用水或酒精擦拭屏幕
4. 避免电子墨水屏受阳光直射，同时要做好紫外线防护措施，带电粒子长时间在强光的照射下会发干，导致失去活性无法刷新

## 设备三种工作状态

### 休眠状态：电源指示灯熄灭
- 单击**电源按键**即可唤醒芯片

### 唤醒状态：电源指示灯常亮
- 短按**模式按键**：切换工作模式
- 长按**模式按键**：启动进入该模式
- 短按**电源按键**：进入永久休眠
- 长按**电源按键**：屏幕刷成全白

### 刷图（屏幕刷新）状态
**电源指示灯闪烁**
> ⚠️屏幕保护提示：请等待指示灯熄灭后，再进行其他按键操作，不要中途打断刷新。

## 按键功能
### 电源按键
- 休眠状态：单击唤醒芯片
- 唤醒状态：
    - 单击进入永久休眠
    - 长按刷白屏幕


### 模式按键（唤醒状态下生效）
- 短按：切换工作模式，通过模式指示灯确认模式
- 长按：进入该模式，执行对应代码

## 指示灯对照表
| 指示灯     | 状态     | 说明                       |
| ---------- | -------- | -------------------------- |
| 电源指示灯 | 常亮     | 设备正常工作（唤醒状态）   |
| 电源指示灯 | 熄灭     | 设备休眠                   |
| 电源指示灯 | 闪烁     | 正在刷新屏幕，请勿操作按键 |
| 模式指示灯 | 快速闪烁 | 轮播模式                   |
| 模式指示灯 | 慢闪烁   | 服务器模式                 |

## BMP图片制作
Release 文件夹提供转换工具：`convert.exe`、`converterTo6color_all.cmd`

方式1【单张转换】：直接将图片拖拽到 `convert.exe`，自动生成适配图片
方式2【批量转换】：把待转换图片放到与`convert.exe`相同文件夹，双击运行 `converterTo6color_all.cmd` 批量转换

> 若提示：“由于找不到VCRUNTIME140D.dII / ucrtbased.dll，无法继续执行代码。重新安装程序可能会解决此问题。”
>
> 把文件夹内的两个 .dll 文件放到目录`C:\Windows\System32`即可

## TF卡故障排查（轮播模式刷新内置图片）
按顺序逐项检查：
1. TF卡内没有有效的BMP图片文件
2. TF卡识别异常
   - TF卡松动：取出TF卡，用纸巾擦拭金属触点后重新插入
   - 文件系统损坏：电脑格式化TF卡为 **FAT32**

### TF卡使用注意事项
1. 文件名仅使用英文、数字，**禁止中文命名**，文件名长度不超过127个字符
2. 配置文件丢失/误修改，设备自动使用默认参数：
   - 轮播间隔：6小时
   - 关闭子文件夹循环轮播
   - 仅刷新TF卡读取到的第一张图片
3. Release文件夹内有标准配置文件，复制放置到TF卡**根目录**即可生效
